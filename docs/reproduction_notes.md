# Reproduction Notes

The manuscript uses controlled numerical simulations to study the behavior of an operational-profile-aware imprecise Bayesian reliability assessment method. The simulations are methodological demonstrations, not industrial field validation.

## One-Command Reproduction

From the repository root:

```bash
python simulation.py
```

This regenerates the figures, generated validation counts, parameter table, and result summaries.

## Fixed Settings

The complete fixed numerical configuration is stored in:

```text
config/simulation_config.yaml
```

The random seed is:

```text
20260611
```

The finite prior scenario set is generated from the declared lower/upper prior success probabilities and lower/upper Dirichlet prior strengths. The finite operational-profile scenario set contains the nominal and stressed profiles declared in the YAML file.

## Manuscript Value Checks

The main numerical checks are:

- `results/validation_allocation_summary.csv`
  - risk-targeted allocation reaches `R_req` at `N_add = 1250`;
  - uniform allocation reaches `R_req` at `N_add = 1500`;
  - profile-proportional allocation reaches `R_req` at `N_add = 2000`.
- `results/unsafe_recommendation_summary.csv`
  - single-demand `p_hat_unsafe = 0.00492`;
  - mission-level unsafe screening values are approximately `0.199`, `0.256`, and `0.389` for `n=45`, `n=60`, and `n=100`, respectively.

## Data Boundary

All numerical files are generated by the scripts. No real industrial field logs, proprietary maintenance data, or private diagnosis records are included.
