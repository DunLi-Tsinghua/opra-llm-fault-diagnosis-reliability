# Generated Numerical Data

This directory contains generated synthetic validation counts and parameter tables for the controlled numerical experiments in the manuscript.

Important:

- The files are generated by `python simulation.py`.
- No proprietary industrial data are included.
- No raw field logs, maintenance records, sensor histories, or private diagnosis traces are required.
- The validation counts are controlled synthetic numerical data sampled from the generating probabilities declared in `config/simulation_config.yaml`.

Files:

- `generated_validation_counts.csv`: generated validation counts by task domain and diagnostic outcome.
- `simulation_parameters.csv`: parameter table containing domains, operational profiles, true generating probabilities, validation sample sizes, prior scenarios, severity weights, and thresholds.
