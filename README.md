# OPRA LLM Fault Diagnosis Reliability

This repository is the reproducibility package for the manuscript:

**An Operational-Profile-Aware Reliability Assessment Framework for LLM-Assisted Fault Diagnosis under Epistemic Uncertainty**

The repository contains the controlled numerical simulation code, fixed configuration files, generated validation counts, result summaries, and figure-generation scripts used for the manuscript. The study uses **controlled synthetic numerical data only**. It does not include real industrial field data, proprietary maintenance logs, private diagnostic records, or raw plant/asset data.

## Repository Contents

- `simulation.py`: top-level entry point for regenerating all controlled numerical outputs.
- `scripts/simulate_reliability.py`: simulation, reliability-envelope, validation-planning, unsafe-screening, and figure-generation code.
- `config/simulation_config.yaml`: fixed numerical settings, including the random seed, operational profiles, true generating probabilities, prior scenarios, severity weights, thresholds, and mission lengths.
- `data/`: generated synthetic validation counts and parameter tables.
- `results/`: numerical summaries used for manuscript tables and cross-checks.
- `figures/`: regenerated PDF and PNG figures corresponding to Fig. 1--Fig. 8 in the manuscript.
- `docs/reproduction_notes.md`: additional notes for checking the reproduced values.

## Installation

From a clean Python environment:

```bash
pip install -r requirements.txt
```

## Reproducing the Controlled Numerical Results

Run:

```bash
python simulation.py
```

This command regenerates:

- all figures in `figures/` as PDF and PNG;
- `data/generated_validation_counts.csv`;
- `data/simulation_parameters.csv`;
- `results/simulation_summary.csv`;
- `results/validation_allocation_summary.csv`;
- `results/unsafe_recommendation_summary.csv`.

The fixed random seed is `20260611`, defined in `config/simulation_config.yaml`.

## Expected Cross-Checks

After running `python simulation.py`, the generated summaries should include:

- validation-planning crossing values:
  - risk-targeted: `1250`;
  - uniform: `1500`;
  - profile-proportional: `2000`;
- unsafe recommendation screening:
  - `p_hat_unsafe = 0.00492`;
  - mission-level values approximately `0.199` at `n=45`, `0.256` at `n=60`, and `0.389` at `n=100`.

These values correspond to controlled numerical examples only. They are not empirical estimates from industrial field deployment.

## Data Statement

All CSV files in `data/` and `results/` are generated by the included scripts from the parameter settings in `config/simulation_config.yaml`. No proprietary industrial data are included, and no raw field logs are required.
